# Project 9: Notepad Application

A Java Swing desktop text editor built with Apache NetBeans and Maven.

---

## 📌 Project Overview
This desktop application provides core text editing capabilities with file management, text manipulation, and formatting options. Developed as part of our Software Development / Computer Engineering group project.

---

## 🚀 Key Features
- **File Operations:** New file, Open existing file, Save, Save As, and Print.
- **Editing Tools:** Cut, Copy, Paste, Select All, and Clear.
- **Text Formatting:** Custom font family, font style, and font size configuration.
- **User Interface:** Clean Java Swing GUI with scroll pane and real-time word/character count status bar.

## 🛠️ Tech Stack & Requirements
- **Language:** Java (JDK 17+)
- **Build Tool:** Apache Maven
- **IDE:** Apache NetBeans
- **GUI Framework:** Java Swing (`JFrame`, `JTextArea`, `JMenuBar`, `JScrollPane`)
- **Version Control:** Git & GitHub

## 💻 How to Clone and Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/Thapelo910/SDN-Project1.git](https://github.com/Thapelo910/SDN-Project1.git)
2. Open Apache NetBeans.
3. Go to File -> Open Project... and select the cloned NotepadApp folder.
4. Clean and build the Maven project.
5. Run NotepadApp.java (or the primary GUI class).
