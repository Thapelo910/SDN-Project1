# Notepad Application - User Guide

Welcome to the Notepad Application user manual. This document covers how to compile, run and use the Notepad application.

## 1. What is this app?
This is a basic Notepad app in Java. You can use it to write, edit, save and open text files.

## 2. How to Run the App
1. Open the project in NetBeans / IntelliJ / VS Code
2. Find the file `NotepadGUI.java`
3. Right-click it and click `Run File`
4. The Notepad window will open

## 3. How to Use It

### New File
Click File > New to clear the screen and start a new document.

### Open File
Click File > Open, select a .txt file and click Open and your text will appear.

### Save File
Click File > Save. Type in a filename such as test.txt and click Save.

### Edit Text
Use Edit > Cut, Copy, Paste to edit your text. You can also use Ctrl+X, Ctrl+C, Ctrl+V.

### Change Font
Click Format > Font. Select the font style and size and then click OK.

### Word Count
Look at the bottom of the window (it'll show you how many words you've typed) and it will update as you type.

## 4. If There Is An Error
If you attempt to open a file that doesn't exist you'll get an error message (it won't crash). Simply click OK and try again.

## 5. Testing
The app has been tested with unit tests for word count and file save. All the tests pass.
